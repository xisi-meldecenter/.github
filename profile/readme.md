# Xisi Meldecenter GmbH

**Die nächste Generation Meldecenter.**

Xisi automatisiert Meldungen: sicher, intelligent und zuverlässig. Unsere API sorgt dafür, dass Payroll- und HR-Systeme Meldungen mühelos erfüllen, mit Technologie, der man vertrauen kann.

## Produkte

- **[Xisi-Meldecenter](https://www.xisi.de)**<br>
  Xisi-Meldecenter ist eine zentrale API für die Verwaltung und Übermittlung aller payroll-spezifischen Meldungen.
- **[Xisi-eAU](https://www.xisi-eau.de)**<br>
  Die eAU. Den Rest machen wir. Eine einzige API, gehostet und immer aktuell.
- **[Xisi-euBP](https://www.xisi-eubp.de)**<br>
  Mit Xisi-euBP einfach die elektronisch unterstützte Betriebsprüfung (euBP) versenden. (API)
- **[euBP-senden.de](https://www.eubp-senden.de)**<br>
  Der einfachste Weg euBP-Dateien an die Rentenversicherung zu versenden. (Webupload)
